# 🚀 NovaBlog - Modern Multi-Page Blog Website

A modern, responsive, and visually stunning multi-page blog website built using **HTML, CSS, and JavaScript**. This project was created as part of a **Web Development Internship Task** to demonstrate front-end development skills, responsive design principles, and interactive user experiences.

---

### 🏠 Beautiful Homepage

* Modern Hero Section
